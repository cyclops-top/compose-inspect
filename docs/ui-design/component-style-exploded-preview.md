# 单组件立体样式预览设计方案

macOS 桌面端已实现此交互。用户在右侧检查器点击「立体预览」，在主窗口中央打开弹窗，查看当前组件从外到内的外观操作。例如，同一个组件先后应用两次 padding，中间绘制蓝色背景，弹窗会给出三个可分别选中的层。选择某一层即可同时看到它在序列里的位置、它覆盖的区域和它的属性。

## 入口与布局

入口位于当前组件的「自身样式」标题旁。打开时绑定当前快照和组件，默认选中最外层。标题显示组件名。可拖动弹窗边缘调整大小，下次打开恢复上次尺寸。关闭弹窗后焦点回到入口，主界面保留组件选择。快照替换时关闭绑定旧快照的弹窗。

| 左侧 · 2.5D 堆叠（约六成宽） | 右侧 · 当前层（约四成宽） |
| --- | --- |
| 固定斜视角，第 1 层在底部，后续各层向上靠近内容，所有层共用屏幕坐标系和缩放比例 | 标题显示「第 2 / 4 层 · 背景」，下方先显示单层正视预览，再列出该操作的属性 |
| 选中层原位描边，层号同步高亮 | 底部提供↓ 和 ↑ 图标按钮，按钮与方向键共享选择状态 |

## 选择与切层

- 每个有序样式条目占一个位置。同类型操作与相同边界均保留各自序号。只使用当前组件已关联的样式记录，祖先和内部组件有各自的检查入口。
- 点击可见层面、轮廓或层号即可选中。选中时仅更新描边与层号，所有平面保持原位。层间距只表达操作顺序。
- 下键或左键向外，上键或右键向内，首尾停住，边界按钮禁用。鼠标直接选层后，方向键从新位置继续。几何重叠或层数较多时，可通过带序号的层选择菜单直达任一条目。
- 单次选择同时更新高亮、正视图、属性与按钮状态。快速连续按键以最后选中项为准。开启系统「减少动态效果」时直接切换到终态。层号、类型和选中状态提供给辅助功能，Esc 关闭弹窗。

## 单层预览与属性

| 操作 | 预览形态 | 右侧属性 |
| --- | --- | --- |
| Padding | 画出四条内边距带，中央留空，各边对应方位标值 | 本次操作的上、右、下、左值（dp）及实测层边界（px） |
| Background | 在棋盘格上按本层形状绘制颜色 | ARGB、独立 alpha、形状及可取得的角尺寸 |
| Clip | 以轮廓和裁剪范围表示作用区域 | 形状、各角实际半径及已采集的配置值和单位 |
| 阴影（后续采集扩展） | 有可解释的阴影参数时绘制示意 | 展示实际采集到的字段，例如高度、颜色或形状，并标明单位 |
| 已识别但未解析的操作 | 保留顺序，以虚线框标示已知边界 | 运行时名称、未解析原因，以及仍可读取的字段 |

背景自身的圆角随背景层显示。外层已解析的 clip 会裁剪后续各层的可见范围，多次裁剪取交集。斜视图、正视图与点击命中共用裁剪结果。带形状的背景只影响自身绘制。独立 clip 占一层，即使两者圆角数值相同也可以分别检查。首版沿用现有样式目录；只有在快照记录了对应操作时才建立层。没有阴影采集能力的快照无法据此判断组件的阴影高度。未知形状仅标识已测边界。

例如，依次点选「外侧 padding 8 dp → 蓝色圆角背景 → 内侧 padding 12 dp → clip」，蓝色面应位于两圈边带之间。用户按一次右键，就能从蓝色面的正视图切到内侧留白，直接判断哪圈留白位于蓝色范围内。

## 最终截图与重叠组件

提供「截图局部」作为参考，按当前组件的选择边界与图像有效区域的交集裁切最终截图。A、B 两个平级图片组件重叠时，打开 A 只遍历 A 的操作。截图局部会保留覆盖在 A 上方的 B；被遮挡的 A 像素无法从结果图恢复。各层使用采集到的几何、颜色与形状绘制。无截图时仍可检查已知样式。

## 实现落点

macOS 侧读取 InspectorNode.style，以 ComponentStyle.layers 的数组顺序生成平面。使用 selectionBounds 统一适配视口，保留各层相对偏移；padding 在绘图时按 density 从 dp 转换为 px。复用已有形状路径和 padding 区域计算，先在组件坐标系生成单层几何，再分别用于左侧投影和右侧正视图。投影后的路径同时用于命中检测，便于处理透明中心、细边带与重叠平面。弹窗单独保存选中层序号，无需改动主界面的节点选择。

现有采集、宿主内关联、未知样式处理及坐标语义见[当前组件的分层样式预览](../component-style-preview.md)。相关代码见[检查器与画布](../../macOS/Sources/ComposeInspectApp/InspectorView.swift)、[样式模型](../../macOS/Sources/ComposeInspectCore/ComponentStyle.swift)和[形状路径](../../macOS/Sources/ComposeInspectApp/ComponentStyleDrawing.swift)。

## 验收场景

1. 打开含两层 padding 和背景的组件，层序与「自身样式」一致。两次 padding 可分别选中，正视图只显示各自的数值。
2. 依次点击层面、按上下键、使用层选择菜单，原位高亮、右侧预览和序号始终一致。首尾按键保持当前层。
3. 两个相同边界的背景均可通过键盘和菜单选中。关闭动态效果后仍可通过描边和序号辨认选中层。
4. 选中含背景圆角和独立裁剪的组件，可以分别检查两层的形状。未解析的操作仍可定位，详情给出原因。
5. A、B 图片平级重叠时，A 的截图局部保留遮挡，操作序列仅来自 A。没有截图但有样式记录时，左右两侧的层预览仍可用。
6. 未取得样式记录时，入口旁提示「未取得组件样式」；已关联记录但层数组为空时提示「未采集到外观层」。两种状态均禁用入口。仅一层时可打开并检查，前后切换均禁用。
