# CompScope UI 设计

面向 Android Jetpack Compose 开发的 macOS 检查工具。通过截图选择组件，查看节点信息，并将必要定位信息和修改要求复制为简短文本，交给 AI 修复。

## 设计稿

- [查看静态线框图](compose-inspect-wireframe.html)：完整 HTML，可在浏览器中打开。
- [可编辑源稿](compose-inspect-wireframe.fragment.html)：保留布局与样式的 HTML 片段。

当前为静态设计，所有设备、截图、节点属性和源码位置均为示例；控件不接入实际检查能力。

对应的可运行原生界面已建立，见 [macOS 应用工程](../../macOS/README.md)。本目录 HTML 继续作为静态设计参考。

## 布局

- 顶部：紧凑的单行工具栏，保留窗口控制、设备、应用选择与获取界面入口，不展示应用名和示例说明；常规宽度目标高度约 44pt。
- 左侧：组件树，选中项与截图中的目标组件对应。
- 组件树交互：单击立即选中，双击展开/收起有子节点的行，双击的第一次点击也完成选择；展开箭头可独立操作，支持键盘方向键导航。
- 中间：界面截图与底部节点路径；组件选择、线框显示开关和适合窗口三个控件悬浮在预览区域右下角，不再占用顶部工具栏。
- 右侧侧边栏：选中节点的源码位置、布局，以及组件参数、修饰符、语义的勾选窗口；勾选项用于当前问题的 AI 上下文。
- 底部左侧：有描述的组件自动形成的问题列表；点击一项即选中对应控件。
- 底部右侧：当前问题的关联组件、问题描述输入、精简文本预览，以及复制当前问题/全部问题的入口。
- AI 文本预览可通过编辑区右上角“AI 预览”开关收起或展开，状态自动记忆；收起时描述输入占满右侧宽度，文本生成和复制继续工作，展开时输入与预览之间可调整宽度。

采用 macOS 窗口结构、系统字体、紧凑工具栏，上半区三栏、下半区左右分栏，支持浅色和深色外观。设计稿展示三个问题，当前编辑问题 01，关联 Button「登录」。

整体采用紧凑的一屏布局，桌面常规宽度下目标总高度约 760–800pt：减少预览留白、缩小截图显示比例、压缩右侧属性间距，底部问题区约占四分之一。描述输入与复制预览在桌面宽度下并排；问题列表每项两行，参数数量与组件同排。语义等次要参数组默认折叠。真实应用窗口缩小时，各数据面板独立滚动，预览按可用空间等比适配，上下分栏可调整，不让参数或问题数量把整窗撑长；静态稿窄屏允许自然重排。

## 多问题与参数选择

操作以组件为中心：用户点击截图或组件树选中组件后，底部输入区直接显示该组件的描述。输入非空内容即自动创建一条问题，无需新增或保存按钮；无内容或仅有空白则不记录。清空已记录组件的描述后，该问题从列表移除，仍保留组件选中状态。

同一组件在当前快照中对应一条问题，再次选中时恢复并编辑已有描述，不重复创建；对该组件的多个修改可写在同一段描述中。不同组件分别保存描述和参数选择。只选组件、只勾选参数都不会创建问题。

不设置问题标题字段，也不要求命名。用户只需填写问题描述；列表自动显示序号、关联组件、描述首行预览和已选参数数。描述预览直接取原文，不调用 AI 生成标题。未输入描述的组件不出现在问题列表中，AI 根据定位信息与描述识别问题。

右侧参数窗口按修饰符、组件参数和语义分组，显示参数名称、当前值和勾选框。默认不附加所有参数，只将用户勾选项加入当前问题；定位必需的源码位置、组件名及消歧文字仍自动保留。

切换组件前自动保留原组件的非空描述，输入区随后显示新组件的描述。点击左侧问题列表时，截图高亮、组件树、参数和输入框同步定位对应控件。问题只属于本轮抓取，点击相机开始新一轮时清空。

当前稿仍是静态示意，组件选择、输入自动记录、问题定位、参数勾选和复制均未实现交互。

## 显示线框

开关位于截图预览区右下角的悬浮工具组，与组件选择、适合窗口控件并列；紧凑标签为“线框”，含义为“显示线框”。工具组锚定预览容器，不随图片缩放和平移，位于节点路径上方，保留边缘间距。当前稿展示开启状态，以细虚线叠加普通组件边界，选中组件使用更明显的实线框和节点标签。

预期行为：开启时显示截图上的组件边界；关闭时隐藏普通组件线框，保留当前选中组件的高亮，方便继续定位。开关只控制显示，不改变组件选择、节点数据或复制内容。本次仅绘制开关，不实现交互。

## 复制给 AI

默认保留源码位置、目标组件、明确勾选的参数及修改要求，不复制完整组件树或未勾选的普通属性。缺少源码位置时，使用可用的组件路径与文本描述定位，不生成虚构位置。可复制当前问题，也可将当前界面的多个完整问题按列表顺序合并复制；批量文本逐项保留各自定位与需求。

示例：

```text
LoginScreen.kt:86
Button「登录」
height=48dp
将登录按钮高度改为 56dp。
```
